## Mods

| Project | What it does | Loaders | Get it |
|---|---|---|---|
| **[Ala Industrial](https://github.com/AlaVatra/AlaIndustrial)** | A technology mod: EU energy, voltage tiers, generators, cables and machines. | Fabric, NeoForge | [CurseForge](https://www.curseforge.com/minecraft/mc-mods/ala-industrial) · [Modrinth](https://modrinth.com/mod/ala-industrial) · [Wiki](https://wiki.alaindustrial.org/) |
| **[Ala Logger](https://github.com/AlaVatra/AlaLogger)** | Share a log or crash report with one command. Secrets are stripped before the file leaves your machine. | Fabric, Quilt, NeoForge, Forge | [GitHub releases](https://github.com/AlaVatra/AlaLogger/releases/latest) |
| **[Ala Screen](https://github.com/AlaVatra/AlaScreen)** | Turn a screenshot into a short link with one key. Client side. | Fabric, Quilt, NeoForge, Forge | [GitHub releases](https://github.com/AlaVatra/AlaScreen/releases/latest) |
| **[Ala Modlist](https://github.com/AlaVatra/AlaModlist)** | Share what you have installed as one link. | Fabric, NeoForge | [GitHub releases](https://github.com/AlaVatra/AlaModlist/releases/latest) |

Ala Industrial supports Minecraft 26.3 and 26.2. See each repository for the exact versions.
